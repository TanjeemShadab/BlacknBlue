# Design: Black n Blue Events Logistics Website

**Date:** 2026-04-10  
**Topic:** Complete Website Design for Black n Blue Events Logistics  
**Status:** Validated

## Goal
Create a premium, modern, and visually stunning website for **Black n Blue Events Logistics** in Dhaka, Bangladesh. The site must showcase capabilities, build trust, and generate leads through a high-impact dark-themed aesthetic.

## 1. Visual Identity & Theme
- **Theme:** High-End Dark Mode.
- **Backgrounds:** Oled Black (#000000) and Deep Midnight Navy (#00001A).
- **Accents:** Electric Blue (#00BFFF) for glows, hover states, and CTAs.
- **Typography:**
    - Headlines: *Montserrat* or *Space Grotesk* (Bold, Uppercase).
    - Body: *Inter* (Clean, Professional).
- **Style:** Glassmorphism, subtle blue lighting/glow effects, and large impactful imagery.

## 2. Technical Stack
- **Framework:** React (Vite-powered).
- **Styling:** Vanilla CSS (Modern Flexbox/Grid) with some custom utility patterns.
- **Animations:** GSAP (ScrollTrigger, SplitText) and Framer Motion for layout transitions.
- **Optimization:** Image lazy-loading, WebP assets, and Lenis smooth scrolling.

## 3. Component & Interactive Design
- **Hero:** Full-screen video background with reveal animations.
- **Header:** Glassmorph sticky navigation with shrink-on-scroll.
- **Services:** Hover-revealing cards with Electric Blue glow effects.
- **Portfolio:** Masonry grid with smooth category filtering (Framer Motion).
- **Lead Gen:** Floating WhatsApp button (Pulse effect) and prominent CTAs on every page.

## 4. Page Structure
- **Home:** Authority-building pitch with massive scale visuals.
- **About:** Story of reliability and 10+ years experience in Dhaka.
- **Services:** Detailed breakdown of all 9+ core logistics services.
- **Portfolio:** Visual proof categorized by event type (Concert, Wedding, Corporate).
- **Contact:** Frictionless "Quick Quote" form and direct WhatsApp/Phone links.

## 5. SEO Strategy
- **Keywords:** Event Logistics Dhaka, Exhibition Stall Bangladesh, Stage & Lighting Rental Dhaka.
- **Performance:** Optimized Core Web Vitals (Super fast loading).
- **Accessibility:** Proper heading hierarchy, alt tags, and high-contrast text.
